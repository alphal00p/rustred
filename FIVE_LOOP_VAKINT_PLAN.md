## Graph and symbolic interfaces

Generate scalar vacuum graphs through the existing FeynGen/FeynKit pipeline,
retaining relevant tadpoles/factorizations. Compare exact routing equivalence
to the four maximal 12-line parent representatives and 67-class TIDE census
(48 nonfactorized, 19 factorized). Do not equate graph-isomorphism counts with
integral classes. Preserve explicit physical-to-artifact slot maps.

Use existing compact/exported DOT -> FeynKit diagram/family -> Vakint native
ingress. Add explicit pinches while preserving simultaneous momentum routing.
Do not introduce a parser or dispatch on topology names.

The opt-in RustRed backend with `substitute_masters=false` returns exact
family-qualified terminal coefficients and common-mass factors. Five-loop
numerical substitution is unsupported, with no FORM fallback. Factorized
outputs use canonical exact products where established, including correct
treatment of cross-factor tensor contractions. Existing defaults and 1--4L
behavior remain intact.
