# Opt-in loop-integration outer-map choices

This experiment composes an Insertion/Carpet edge's stored outer map with full marked child automorphisms. A changed momentum map also carries the exact induced physical line_slots and merged_slot permutation; native verify_edge_map rechecks each candidate. Default census/reduction behavior is unchanged.

The score counts terms of the actual post-integration elementary factors (contractions, residuals, free bilinears and insertion carrier squared), with the existing StaticScore rank-one/rank-two proxy. Keep the stored map on ties. This is a static candidate selector, not a performance claim.

Run the native editor explicitly:
    p_outer_maps BASE NEW_OUT REPORT.json 61,64,19,158 129

The fixed measurement base is the6c49 no-orbits combo3 package. Only allowlisted edge maps can change;129 is an identity-group control. The helper copies payloads, bases, order and saved census routes unchanged, then reloads the result. Tests use exact genuine edge fixtures from that same context and check marked physical permutations, inverse/orientation, scalar-product term counts and strict/tie behavior.

IMPORTANT: current PLibrary cache identity does not digest EdgeMap contents. This is measurement-only: disable persistent step caches in both compared runs and bind source, manifest and report externally. No ordering tag or production cache-identity claim is introduced. Production adoption requires an explicit map-choice identity design.

Build/test only the focused public integration target outer_map_choice, then examples p_outer_maps and p_path_census with the full1,2,5,9,14 runtime registry and mimalloc.
