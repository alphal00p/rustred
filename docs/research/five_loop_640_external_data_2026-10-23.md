## Native package and compression

The application exporter authenticates the source and exactly compares every
source substitution and guard with its native compact-map round trip. The
runtime contains 67 owners, two overlays, all queries and terminal maps. It does
not contain the campaign traversal ledger or refinement search matrix.

The new terminal-map encoding is 581,031,505 bytes before transport compression.
This exceeds GitHub's ordinary per-file limit. A small generic RustRed change
uses the same authenticated gzip chunks already used for owner programs; the
native Symbolica encoding, mathematical metadata and decoded map digest do not
change. Legacy raw terminal-map descriptors remain readable. New readers check
declared decoded size before I/O, chunk hashes, gzip integrity, trailing data
and the complete native digest. The 32 MiB chunk size bounds individual files,
not the total allowed native artifact size.
